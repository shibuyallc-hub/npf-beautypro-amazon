# ビューティープロ Amazon広告 効果ダッシュボード

ドッグ（SB）／キャット（SB）／ビタワン（SP）を切り替えて、サマリー・日別推移・検索語句を見るダッシュボード。パスワードが必要です。

## 仕組み
- `index.html` … 画面（HTML/CSS/JS 1枚）。パスワード入力 → ブラウザ内で復号して表示。
- `data/data.enc.js` … 暗号化したデータ（AES-GCM／PBKDF2）。パスワードがないと中身は読めない。
- 平文のデータ・パスワード・作成スクリプトはこのリポジトリに含めない（ローカルのみ）。

## 更新（ローカルのみ）
1. レポートシート（ビューティープロ_Amazon広告効果共有レポート）を最新にする。
2. シートの数字をローカルの `source.json` に書き出して `python3 build_data.py` を実行 → `data/data.enc.js` が作り直される（実行時にサマリーとの突き合わせあり）。
3. `git add data/data.enc.js && git commit && git push`
